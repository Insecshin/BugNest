# BugNest 提测单

## 1. 本次开发内容

- 本次提测范围：Account 注册、邮箱规范化、密码策略、Argon2id 哈希和注册响应。
- 新增 `POST /auth/sign-up`，正式用户从内存 `User` 注册链路切换为 PostgreSQL `Account` 链路。
- `confirmPassword` 只用于确认输入，不进入模型、数据库或日志。
- 注册成功只返回数据库生成的 `userId`。

## 2. 需求 / Issue

- 需求：实现正式账户注册和密码安全存储。
- Issue 编号：未提供，待补充。

## 3. 改动范围

- 新增 `Account`、`AccountService`、`AccountController` 和 JDBC Repository。
- 新增密码 NFC 规范化、长度校验、确认密码校验和本地弱密码黑名单校验。
- 使用 Argon2id 保存密码哈希，不保存明文密码。
- 重复邮箱或用户名由数据库唯一约束兜底，并转换为 `409 Conflict`。

## 4. 接口变化

| 方法 | 路径 | 请求 | 成功响应 | 失败响应 |
|---|---|---|---|---|
| POST | `/auth/sign-up` | `email`、`password`、`confirmPassword`、`nickname` 必填；`userName` 可选 | `201 Created`：`{"userId":123}` | `400 Bad Request`：参数或密码策略失败；`409 Conflict`：邮箱或用户名冲突；数据库基础设施异常未统一定义 |

## 5. 数据库变化

- 数据库：PostgreSQL。
- Migration：依赖 V1 创建 `app_users`，V2 将 `username` 重命名为 `nickname` 并设置非空约束。
- 表/字段：使用 `user_id`、`user_name`、`nickname`、`email`、`password_hash`、`created_at`。
- 约束/索引：`user_name` 唯一；邮箱使用 `lower(btrim(email))` 唯一索引；`password_hash` 非空。
- 运行时使用情况：`AccountService` 生成密码哈希后，由 `JdbcAccountRepository` 使用 `INSERT ... RETURNING user_id` 入库。

## 6. 正常流程

- [ ] 使用合法邮箱、15 个以上 Unicode code point 的密码、相同确认密码和必填昵称提交注册。
- [ ] 验证接口返回 `201 Created`，响应只包含 `userId`。
- [ ] 验证数据库保存的是 Argon2id 哈希，而不是明文密码。
- [ ] 验证邮箱保存前去除首尾空格并转为小写。
- [ ] 验证昵称保存原始 Unicode 文本。

## 7. 异常流程

- [ ] `password` 和 `confirmPassword` 不一致时返回 `400`。
- [ ] 密码少于 15 个 Unicode code point 时返回 `400`。
- [ ] 密码命中当前 blocklist 时返回 `400`。
- [ ] `email`、`nickname` 或必填密码缺失时返回 `400`。
- [ ] 重复邮箱时返回 `409`，且不创建新账户。
- [ ] 明文密码和 `confirmPassword` 不出现在响应、数据库和日志中。

## 9. 测试数据

- 正常注册：`user@example.com`、`123456789012345`、确认密码相同、昵称 `张三`、`userName` 留空。
- 邮箱大小写：` USER@example.com `，预期保存为 `user@example.com`。
- 弱密码：`password123456`。
- 短密码：`short`。
- 重复邮箱：使用已存在账户的邮箱再次注册。
- 重复用户名：使用已存在账户的 `userName` 再次注册。

## 10. 风险点

- 当前未实现邮箱认证，注册邮箱不会经过验证码或确认流程。
- 密码黑名单为本地版本化文件，后续需要持续维护。
- 数据库唯一约束冲突是并发注册下的最终判定，应用层预检查不能替代数据库约束。
- 登录、会话、Token 和密码找回功能不在本次范围内。

## 12. 验收标准

1. [ ] 合法请求能够创建 `app_users` 记录并返回 `201` 和 `userId`。
2. [ ] 响应体不包含密码、确认密码或密码哈希。
3. [ ] 数据库 `password_hash` 不等于任意明文输入密码。
4. [ ] 密码确认失败、长度不足和命中黑名单均返回 `400`。
5. [ ] 重复邮箱返回 `409` 且数据库不产生重复账户。
6. [ ] 全部可运行的单元测试通过；Docker 可用后补充执行 PostgreSQL 集成测试。
