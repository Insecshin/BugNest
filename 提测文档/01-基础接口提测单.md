## 4. 接口变化

| 方法 | 路径 | 请求 | 成功响应 | 失败响应 |
|---|---|---|---|---|
| GET | `/api/ping` | 无 | `200`，`{"data":"pong","message":"ok"}` | 无 |
| GET | `/api/add?a=2&b=3` | `a` 必填整数；`b` 可选整数，默认 `1` | `200`，返回整数 `5` | 参数缺失或格式错误时由 Spring 返回参数绑定错误 |

## 5. 数据库变化

- 数据库：本模块无数据库读写。
- Migration：本模块无新增或修改 Migration。
- 表/字段：无。
- 约束/索引：无。
- 运行时使用情况：接口只执行内存计算和固定响应，不依赖数据库。

## 6. 正常流程

1. 启动应用并访问 `GET /api/ping`。
2. 确认 HTTP 状态码为 `200`，响应包含 `data=pong` 和 `message=ok`。
3. 访问 `GET /api/add?a=2&b=3`，确认返回 `5`。
4. 省略 `b` 访问 `GET /api/add?a=2`，确认按默认值 `1` 计算并返回 `3`。

## 7. 异常流程

- 缺少必填参数 `a` 时，应返回参数绑定错误。
- `a` 或 `b` 传入非整数时，应返回参数绑定错误。
- 具体错误响应 JSON 格式未在项目中统一定义，需记录实际响应。

## 10. 风险点

- `/api/add` 为示例接口，不代表业务计算规则。
